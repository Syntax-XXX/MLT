# BeastMode Linktree

Premium, static-first Next.js landing page for BeastMode's KuKirin partner links.

## Local development

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.

## Content updates

Edit `src/config/links.ts` to change, reorder, enable, or add destinations. Disabled entries are never rendered.

## Deploy to Vercel

```bash
npx vercel --prod
```

The project has no environment variables or backend services.

`public/g2-ultra-full.webp` is an optimized, full-scooter derivative of the product image supplied for this project.
